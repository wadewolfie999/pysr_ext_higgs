# Welcome to the `pysr_ext_higgs` Wiki

<!-- Keep Home brief. The first Start here link leads to the README setup guide; result tables and methodological details belong on their dedicated pages. -->

This project uses **PySR** to search for symbolic classifiers in the **inert two-Higgs-doublet model (i2HDM)**, also known as the **Inert Doublet Model (IDM)**: a **beyond-the-Standard-Model (BSM)** extension of the Higgs sector. Each expression maps two particle masses to a classification score. This Wiki holds the selected result and explains how it is evaluated.

## Start here

1. **[Install and run the project — README](https://github.com/wadewolfie999/pysr_ext_higgs#how-to-run-this-on-your-machine)**

    Follow the eight-step guide to prepare your environment, configure PySR, and start a search.

2. **[Explore the selected result — Project Registry](https://github.com/wadewolfie999/pysr_ext_higgs/wiki/Project-Registry)**

    Inspect `L2HL_1_050`, its ROC-AUC scores, saved figures, and expression downloads.

3. **[Understand the evaluation — Methods and limitations](https://github.com/wadewolfie999/pysr_ext_higgs/wiki/Method-and-Limitations)**

    Read about the loss, data split, selection procedure, and diagnostic plots.
